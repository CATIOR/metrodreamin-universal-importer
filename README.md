# metrodreamin-universal-importer
A browser userscript for MetroDreamin' that imports transit lines, stations, curve waypoints, and pedestrian interchanges directly from GeoJSON, KML, and GPX files into the MetroDreamin' editor.  Works with exports from Google My Maps, QGIS, uMap, OpenStreetMap / Overpass Turbo, GeoJSON.io, Yandex Maps, Strava / Garmin, and any standard software.
